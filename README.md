# 小説工房 / NovelStudio

AndroidでChatGPTの契約プランを使って本文・タイトル候補・あらすじを生成し、作品・話数ごとに保存、編集、読書、投稿準備をする個人用アプリです。挿絵の自動生成には、別途OpenAI APIキーを設定します。個人利用向けで、独自サーバーは不要です。

## 起動から投稿まで

1. APKをAndroid 8以降の端末にインストールします。
2. 「ChatGPTで続ける」から公式認証ページを開き、アプリを承認します。認証は標準ブラウザで行います。「小説工房へ戻って接続を完了」を押し、アプリを開いたまま完了を待ってください。
3. 本棚で作品を作成します。世界観、登場人物、文体を設定し、タイトル候補やあらすじをAIで生成するか、自分で入力します。
4. 執筆画面で話を作成し、利用可能モデルを選んで生成します。「続き」「推敲」にも対応します。
5. 単話生成は候補を確認して採用します。一括生成は本文のない話へ順番に生成し、完成した本文を自動保存します。既存本文を一括生成で置き換えることはありません。
6. 読書画面で本文を読み、必要なら執筆画面で修正します。
7. 投稿画面からなろう・カクヨムの公式サイトをアプリ内に開きます。各サイトへの初回ログインと作品作成は本人が行います。
8. 原稿欄を選び、コピーと貼り付け、または対応する編集欄への入力補助を使って原稿を渡します。公開はサイトの確認画面で操作してください。

画面の見出しやボタン名は更新により少し異なる場合があります。

## 1.4.1への更新

前のアプリをアンインストールせず、1.4.1のAPKを開いて更新してください。添付の1.1.0と同じ署名鍵を使い、versionCodeを8へ上げています。既存の原稿・設定・ChatGPT認証情報を読み込みます。

### 長文の話者解析の修正（1.4.1）

- 全文の区間数・文字数による拒否をやめ、内部で小さな解析要求へ分けて順番に処理します。空白だけの区間はAIに送らず、本文には残します。
- 各要求には前後の文脈と関連するキャラを渡します。既存の人物・手動の声設定を引き継ぎます。
- 「解析を一時停止」で停止し、「保存した続きから解析」で、未解析の部分だけを再開します。再起動・通信エラー・サービス終了後も解析済みの部分を保持します。意図的にやり直す場合のみ「最初から解析」を使います。
- 不完全なJSONなどを受け取った場合は結果を採用せずに停止し、再開時は失敗した部分をさらに小さく分けます。前の有効な話者解析は全区間が完了するまで保持します。
- 進捗を区間数で表示します。解析途中で本文を編集した場合は、変更を検出した次の内部要求の前に停止します。

### キャラ別の読み上げ（1.4.0）

1. 本文を保存し、「読む」画面の「AIで話者・声を設定」を押します。話者判定には既存のChatGPT接続と選択中の文章モデルを使います。1話ごとの解析です。
2. AIが地の文・セリフ・心の声と話者を判定し、キャラをメイン・サブ・モブに分け、声・速度・高さ・音量・間を割り当てます。根拠のない話者は「話者不明」にできます。
3. 「キャラと声」でキャラ名・別名・役割・性別・音声・速度・高さ・音量を編集し、試聴します。同じ作品のキャラ設定は次の話でも保持します。手動保存した設定は再解析で上書きしません。別名も人物の照合に使います。
4. 「話者・読み方を修正」で区間ごとの誤判定を直せます。地の文／セリフ／心の声、話者、感情、演出指示、速度、高さ、音量、区間後の間を編集できます。
5. 「この話を再生」で朗読します。前／次の区間、一時停止、続きから再生に対応します。解析済みの次の話は連続再生できます。未解析・本文が変わった話に進むと止まります。
6. AI解析せず、1種類の声で読む場合は「地の文の声で読む」を使います。

| 音声方式 | 声と演出 | 必要な設定 |
| --- | --- | --- |
| 端末の音声（初期値） | Androidの日本語音声。速度・高さ・音量・間を反映。感情の演技や性別は音声エンジン次第。音声の性別情報はAndroidから取得できないため、試聴で確認 | 日本語の音声エンジン・音声データ。追加APIキー不要。ネットワーク音声を選んだ場合は提供元への通信が発生する場合あり |
| Gemini AI音声 | 30種類の固定音声から選択。提供元の男女分類を表示。会話・内心・感情・囁き・速度・高さを演出指示として送信 | 「音声設定 → APIキーを設定」でGemini APIキーを登録。ChatGPTの契約とは別のAPI利用枠・料金 |

Geminiの標準モデルは `gemini-3.8-flash-lite-tts`、選択肢に `gemini-3.8-flash-tts` を用意しています。利用できるモデル・音声・料金は提供元のアカウントとAPI仕様に依存します。速度・高さの数値はAIへの演出指示であり、厳密な倍率ではありません。音声合成が本文を正確に発音することや、感情・話者のAI判定の正しさは保証できません。特に固有名詞の読みは実際の音声で確認してください。

AI解析時には本文・登場人物設定・あらすじ・声の一覧をChatGPTに送ります。本文は端末で区間分けし、AIからは区間IDごとの注釈だけを受け付けます。解析結果で本文を書き換えません。1.4.1では、読み上げ独自の600区間・60,000文字・200キャラ・16MiBの固定上限を撤去しました。長い本文は内部で分割し、1回のモデル要求を小さく保ったまま最後まで順番に解析します。原稿をユーザー側で分割する必要はありません。端末のメモリ・空き容量、モデルの利用枠や通信状況には依存します。不要な話の解析は「音声設定」から削除できます。

Geminiで再生・試聴すると、その区間の本文と声・演出をGoogleに送信します。同じ本文・音声・演出・モデルの音声は端末キャッシュを再利用します（上限約256MiB、Androidに消去される場合あり）。料金が発生しうる要求の自動再試行・先読みはしません。停止前にすでに送信した要求の課金は取り消せません。キーはAndroid Keystoreで暗号化し、WebViewやバックアップに渡しません。

読み上げは画面と独立したmediaPlaybackフォアグラウンドサービスで実行します。通知・メディア操作から前／次／停止に対応し、イヤホン切断・音声フォーカス喪失で一時停止します。4秒ごと・区間切替・停止時に位置を保存し、再開時は同じ音声ファイルの位置へ移動します。突然の強制終了では直近約4秒分が戻る場合があります。Androidの強制停止・再起動・省電力による終了を完全に防ぐものではありません。再起動しただけで音声やAPI要求を自動再開しません。

キャラ・話者解析・再生位置は既存のZIPバックアップに含まれます。APIキーと音声キャッシュは含まれません。旧バックアップに音声設定がない場合は、既存の音声設定を保持します。作品と音声を合わせたバックアップの上限は29MiBです。

実機の音声出力・バックグラウンド再生・実Gemini APIはこの環境では未検証です。実施済みの自動検証はVERIFICATION.mdを参照してください。

### 最大100話の一括生成

1. 執筆画面で作品設定を入力し、利用するモデル・1話あたりの文字数・執筆指示を設定します。
2. 「複数話をまとめて生成」の話数を1〜100で指定します。10・50・100話のボタンでも指定できます。初期値は100話です。
3. 必要なら「連続生成の展開・各話プロット」に全体の流れや各話の内容を入力します。
4. 「指定した話数を連続生成」を押します。末尾に話を追加し、1話ずつ生成・保存して次へ進みます。選択中の話が末尾の完全な空白話なら、その話を最初の1話として使います。
5. 進捗は「37 / 100話」のように表示します。別タブ・別アプリに移っても、次話の開始を含めてネイティブ処理が担当します。
6. 「一時停止」で止め、「保存した続きから再開」で再開できます。完成済みの話は再生成せず、中断した話の保存済み末尾から続けます。アプリの再起動後にも進捗を復元します。

一括生成の対象になる未完了の話は、処理を終了するまで本文編集をロックします。「この一括生成を終了」を押すと、完成した原稿・途中候補を残して個別に編集できます。完了後は「完了を確認・次の一括生成へ」で次の一括生成を開始できます。新しいキューを開始する前に、前の結果が原稿へ保存されたことを確認します。

生成を始めた時点の設定・モデル・プロットを使います。直前3話の全文と、それ以前の生成済み話の冒頭・末尾抜粋（最大60話）を文脈に含めます。100話分を一つの応答で生成する方式ではありません。利用枠の不足、通信切断、保存失敗などでは停止します。エラー後・プロセス終了後の自動再送はせず、再開ボタンから続けます。

### 単話の途中再開

中断・通信エラー・手動停止した生成候補に「途中から再開」を追加しました。受信済みの本文を残し、元の指示とその本文を送って未出力部分を続けます。これは保存した末尾からの新しい生成要求であり、切断前のサーバー処理へ再接続するものではありません。元の原稿と採用・取り消しの挙動は維持します。旧版で作成した候補に元の指示がない場合は、現在の作品設定を使って続けます。

### タブ切り替え・別アプリ・画面消灯中の生成

本文、タイトル候補、あらすじ、APIを使う挿絵生成を、画面から独立したネイティブ処理へ移しました。生成はアプリを開いて開始します。開始後は、アプリ内の画面切り替え、別アプリへの移動、画面消灯、Activityの再作成を理由にアプリ側で中止しません。

- 生成中はAndroidのフォアグラウンドサービスとCPU用のWakeLockを使用します。画面を点灯したままにする必要はありません。
- 初回生成時に通知の許可を求めます。許可すると、通知から進行状況を確認し、生成を中止できます。文章と挿絵を同時に処理している場合、通知の中止ボタンは両方を中止します。終了時も通知します。通知を拒否したことだけで生成を中止することはありません。
- 受信した文章は画面側の保存とは別に記録します。最初の未保存受信から約1秒後に途中結果の保存を予定し、完了・失敗・中止時は同期保存します。保存容量を確保できなければ、新しいAPI要求を始めません。
- 戻ったときはネイティブ側の最新結果を読み直します。受信順を管理し、同じ文章や挿絵を二重に追加しません。原稿への反映を保存できたことを確認してから、独立した生成記録を片付けます。
- OSによるプロセス終了、強制停止、端末再起動では通信は続きません。次の起動時に保存済みの途中候補を復元し、中断として表示します。要求を自動再送しないため、画像APIを勝手に再課金する動作はありません。突然の終了では最後の未保存区間が失われる可能性があります。
- Androidの省電力制限、通信断、メーカー独自の制限を無効にするものではありません。必要な場合は設定の「端末の電池設定を開く」から端末側の設定を確認できます。
- Android 15以降のdataSyncサービスには、バックグラウンドで24時間あたり合計6時間の上限があります。上限通知を受けたときは中止・保存してサービスを終了します。アプリ側にも1回の連続稼働に6時間の上限を設けています。詳細：[Androidのフォアグラウンドサービスの時間制限](https://developer.android.com/develop/background-work/services/fgs/timeout)。

アプリ内に開いた公式ChatGPTのWebページで行う生成は、このサービスの管理対象に含みません。本文などのAPI生成と「APIで自動生成」を選んだ挿絵が対象です。Android実機での画面消灯・省電力状態・通知配信は未検証です。

### タイトル候補・あらすじ

作品設定からタイトル候補を5・10・20件で生成できます。候補を比較して採用またはコピーできます。あらすじは作品設定と本文を参考に400〜600字を目安に作成します。生成候補を確認して採用するまで現在のタイトル・あらすじは書き換えません。候補は端末に保存し、生成の中断や失敗があった場合は受信できた文章を残します。件数や文字数はAIへの指示であり、生成結果によって異なる場合があります。

### 挿絵

- 作品設定と選択した話から挿絵の指示を自動で作成します。作品ごとに画風を指定でき、送信内容を確認できます。長い設定や本文は画面に示す範囲を参照します。
- **APIで自動生成**：設定から自分のOpenAI APIキーを登録すると、各話の「挿絵を作成」で1枚を生成し、保存・表示します。ChatGPTの契約料金とは別のAPI従量課金です。初期モデルはgpt-image-2.5-flare、1024×1024、中品質。gpt-image-2.5-sunburstも選択できます。キーの入力はネイティブ画面だけで扱い、Android Keystoreで暗号化してChatGPT認証情報とは別に保存します。
- **ChatGPT画面で生成**：指示をコピーして公式ChatGPTをアプリ内に開きます。指示の貼り付け・送信と画像の保存はChatGPT側で操作し、戻って「画像を取り込む」で追加します。WebViewでログインや保存ができない場合は↗から標準ブラウザを使います。この方法は生成・保存までの完全なワンタップ操作ではありません。
- 現行のSign in with ChatGPT個人向けOAuth APIでは画像生成が未対応です。本文などの文章生成と画像のAPI課金を切り替えて処理することはありません。
- 挿絵は話ごとに保存し、執筆・読書画面に表示します。PNGで書き出せます。取り込みはPNG/JPEG/WebP、16MiB以下、各辺4096px以下、合計16Mピクセル以下です。保存時にPNGへ正規化し、必要に応じて縮小します。1話あたり最大50枚です。
- 挿絵は原稿JSONへ画像本体を埋め込まず、アプリの専用フォルダに保存します。削除操作は話との関連付けを外します。直前の原稿復旧を壊さないよう、画像実体は直ちに削除しません。
- 画像API要求の自動再送は行いません。待機の中止や通信失敗があっても、送信済み要求は課金される場合があります。画面を離れても処理は継続しますが、プロセス終了後に要求を自動再送して再開することはありません。
- 挿絵をなろう・カクヨムへ自動添付する機能は含みません。

## 旧版の接続エラー対策

1.0.1で利用者から`AUTH_TOKEN_DNS`が報告されました。旧版はブラウザが前面にある間に、裏側のアプリで認証情報を取得していました。Android 15以降では、適切なプロセス状態の外から開始した通信が`UnknownHostException`等になることが公式に説明されています。この制限は今回の現象と整合しますが、端末のDNSや回線の問題との切り分けは未完了です。

1.0.2では端末内のコールバックでログイン結果を受け取ると、まず「アプリに戻る」画面を返してリスナーを閉じます。受信結果はメモリ内に保持し、Activityの`onResume()`後に認証情報を取得します。戻るリンクには認証コード等を載せず、ブラウザの画面でもこの時点を「接続成功」とは表示しません。アプリを離れると後続通信が制限される可能性があるため、接続完了までアプリを開いてください。

認証情報を送信する前、`getOutputStream()`が返る前に発生したDNS失敗だけは、2.5秒待って前景・取消・期限を再確認し、同じ認証コードで1回再試行します。本文の書き込み開始後、応答待ち、タイムアウト、HTTPエラーでは再送しません。更新トークン交換のPOSTにも再試行を追加していません。公開鍵のGETは従来どおり、一時的な通信失敗時に1回再取得します。DNSサーバーの変更、VPN回避、証明書検証の無効化は行いません。

1.0.0にあった、認証先との通信タイムアウトを端末内のHTTP待ちとして扱い続ける問題は、1.0.1で修正済みです。

接続に失敗した場合、本棚・執筆画面・設定に理由を表示します。「診断情報をコピー」はアプリのバージョン、処理段階、`AUTH_TOKEN_TIMEOUT`等の固定診断コードだけをコピーします。メール、認証コード、トークン、コールバックURL、生の応答本文は含みません。問題が続く場合はこの診断情報で失敗箇所を確認できます。

更新後も`AUTH_TOKEN_DNS`が続く場合は、Wi-Fiとモバイル回線を切り替え、アプリを開いた状態で再試行してください。今回の版でも実機での認証成功は未確認です。

## GPTへの接続

公式Sign in with ChatGPTの、個人のローカルツール向けOAuthフローを実装しています。

- 本文・タイトル・あらすじの文章生成にAPIキー入力は不要です。ChatGPTの契約プランに従う利用枠を使用します。挿絵APIは別途設定・別料金です。
- 利用可能なモデルはログインしたアカウントのモデル一覧から取得します。固定モデル名や架空の利用枠を表示しません。
- 初回はユーザー承認による動的クライアント登録を行い、発行された登録IDを使います。他アプリのIDを流用しません。
- 認証は標準ブラウザと端末内127.0.0.1の一時コールバックを使います。端末の外にはコールバックを公開しません。
- PKCE、state、nonce、IDトークン署名・発行元・有効期限・宛先を検証します。
- 認証情報はAndroid Keystoreで暗号化し、アプリ専用領域に保存します。WebViewのJavaScriptやJSONバックアップには渡しません。
- 推論は公開Responses APIのストリーミングを使用します。store:falseを指定し、response.completedを受信するまで完了としません。
- 利用上限やネットワーク切断が起きた場合は途中までの候補を残します。自動再試行による重複生成はしません。

生成を実行すると、作品設定や選択した原稿・前話がOpenAIへ送信されます。送信内容はプロンプト確認から確認できます。利用可能モデル、承認の可否、利用枠はアカウントと提供状況に依存します。

## 投稿機能の範囲

公式のログイン済み投稿フォームはユーザー自身の端末で開きます。ログイン資格情報・Cookieをアプリの原稿処理やGPTへ渡すことはありません。

「ワンタップ公開完了」を装う実装ではありません。投稿先を開く、原稿をコピーする、対応した選択欄へ入力する操作を短縮します。作品種別・年齢区分・AI利用表示等はサイト側で設定し、最後に本人が公開します。公開成功を確認していない原稿を勝手に公開済みに変更しません。

### 小説家になろう

2026年11月6日の公式ガイドラインでは、作者による加筆・修正がない全編AI生成作品の投稿は禁止されています。極めて軽微な修正だけでも実質的な全編AI生成として対応対象になる場合があります。アプリで「読んだ」「編集済み」にしただけで規約に適合するわけではありません。

作品設定でAI直接使用・AI間接利用・AI補助的利用・AI不使用の該当区分を選びます。全体を自分の表現に編集したか、一部の生成文章がまとまりとして残るかで区分が変わります。

### カクヨム

2026年5月27日更新の公式案内では、本文の大半（目安50%以上）に生成文章を使う場合は「AI本文利用」、一部の場合は「AI本文一部利用」、補助の場合は「AI補助利用」が推奨されています。実際の利用状況に合うタグを本人が設定してください。

## 端末内の保存とバックアップ

- 作品、各話、生成候補、読書位置、設定を端末内に保存します。
- 編集は自動保存します。ネイティブ保存は一時ファイルからの原子的な置換で行い、直近の有効な保存を別ファイルにも保持します。
- 設定から原稿と参照中の挿絵をまとめたZIPバックアップを出力・復元できます。旧版のJSONバックアップも復元できます。TXTでは作品を文章として出力できます。ZIPは原稿30MiB・画像1枚16MiB・非圧縮合計250MiBを上限とします。
- バックアップにChatGPT認証情報と画像APIキーは含みません。別端末ではログイン・API設定をやり直してください。
- アンインストールや端末のアプリデータ消去で端末内の原稿は失われます。必要な原稿と挿絵は事前にZIPへ出力してください。
- サーバー同期やクラウドへの原稿自動アップロードはありません。

## ビルド

JavaソースとHTML/CSS/JavaScriptだけで構成し、実行時の外部ライブラリは使っていません。

### 付属のオフラインビルダー

JDK 17、Android SDK platform 36、build-tools 35以降を用意し、次を実行します。

```sh
python3 build.py --sdk /path/to/android-sdk --java-home /path/to/jdk \
  --signing /private/novelstudio-signing --output /path/to/novelstudio-1.4.1.apk
```

初回だけ署名鍵を作成します。同じアプリへ上書き更新するには同じ署名鍵が必要です。署名鍵とパスワードはソースZIPに含めず、非公開で保持してください。

### Android Studio

このフォルダをプロジェクトとして開き、JDK 17 / Android SDK 36を設定します。Gradle 8.13以上とAndroid Gradle Plugin 8.13.0を使う構成も付属しています。Gradle経由のビルドは環境に応じて依存物のダウンロードが必要です。納品APKは付属PythonビルダーとAndroid SDKで生成しています。

## 制約と検証

- OAuth承認は本人のアカウントで行う必要があります。納品前に本人の認証情報を使ったログインや実際の小説の公開は行っていません。
- Android実機での起動・認証完了、本人のアカウントを使う文章生成、課金を伴う画像生成、サイト側の認証後投稿フォームには未確認部分があります。ビルドと模擬応答によるオフライン検証の結果はVERIFICATION.mdを参照してください。
- 外部サイトがWebViewログインを許可しない場合は、内蔵の「外部で開く」と原稿コピーを使えます。標準ブラウザとWebViewは通常別のログイン状態を持ちます。
- 生成開始には前面の画面が必要です。開始後は通知付きサービスで継続します。OSの強制停止・プロセス終了・通信断・厳しい省電力制限を越えて継続できる保証はありません。
- アカウント設定や公式仕様の変更でログイン・生成できなくなる場合は、エラーを表示します。Web画面からトークンを抜き取る等の代替手段は実装していません。
- 配布APKは個人向け署名済み版です。Google Playへの登録・公開は行っていません。
